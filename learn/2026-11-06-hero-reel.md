# Home hero reel and one-paragraph letter

> 2026-11-06 · Replace the workshop table hero with a silent looping reel, and rewrite the Home letter into one product paragraph with logos

## In short
The Home hero now leads with a muted, looping build reel at full content width, then the letter. The old workshop stage stays in the repo behind `showHomeWorkshop`. The letter is one paragraph that names Wonderstand, FirstDistro, UseLay, and Sinch as bold links with small inline logos.

## What changed
- `code/app/web/src/component/HeroReel.astro`: new video frame (webm + mp4 + poster), reduced-motion poster, round `/jide.jpg` avatar at the top-left of the frame.
- `code/app/web/public/jide-reel/`: encoded reel assets.
- `code/app/web/src/lib/site-flags.ts`: `showHomeWorkshop` (default false) so the workshop table can come back without deleting code.
- `code/app/web/src/pages/index.astro`: stacked reel-above-letter layout when the flag is off; letter-beside-workshop when it is on.
- `code/app/web/src/component/HomeLetter.astro`: one paragraph with product links and logos; reach line removed.
- `code/app/web/public/brands/`: Wonderstand, FirstDistro, UseLay, and Sinch marks for the inline logos.
- `code/app/web/src/style/home.css`: reel layout, top-left avatar, product link weight 600, wider letter under the reel.
- `code/app/web/script/verify-build-output.ts`: build checks follow the reel flag and the new letter copy.

## How it works
1. `index.astro` reads `showHomeWorkshop`. When false, it adds `home-hero--reel` and renders `HeroReel` above `HomeLetter`.
2. `HeroReel` serves a 16:10 muted autoplay loop with no controls. A tiny script pauses the video when `prefers-reduced-motion` is set, and CSS hides the video so the poster stays visible.
3. The avatar is page UI on the video frame, not pixels inside the encode.
4. The letter maps product data into inline links. Each link shows a 1em logo, then the name at weight 600, then a short blurb in parentheses. Sinch uses the same link style in the closing sentence.

## Why it's built this way
- **Flag, do not delete:** the workshop Three.js stage and stills stay importable. Flipping one boolean restores the old hero without a revert hunt.
- **One format that scales:** one 16:10 reel, full width on mobile and desktop, instead of a separate tall cut.
- **Logos as `<img>`, not inlined SVG markup:** keeps the letter markup short and lets each brand file stay the source of truth.

## Concept worth knowing: feature flags for UI
**Simply put:** a light switch for a room. The wiring stays in the wall; the switch only chooses on or off.

**More precisely:** `showHomeWorkshop` is a build-time constant. Astro renders one hero branch or the other into static HTML. The unused island is still in the source tree, so turning the workshop back on is a one-line change plus a rebuild.

## Watch out for
- Footer has X, LinkedIn, and GitHub, but no email. The letter no longer links email either.
- Product links use `white-space: nowrap` so logo and name stay together. On very narrow viewports that can force horizontal wrap of the sentence around the whole chip.
- Reel assets are a few megabytes in git. Re-encoding later should keep muted webm + mp4 + poster in sync.
- What to test: Home on desktop and phone, reduced-motion (poster only), and `showHomeWorkshop = true` still mounts the workshop.
